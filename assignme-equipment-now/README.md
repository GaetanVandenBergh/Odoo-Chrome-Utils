# Odoo-AssignMe-Equipment

## What it does

This extension adds an **"Assign to me"** button directly on Odoo maintenance equipment form views.

When you open a maintenance equipment record, a button appears next to the **Technician** field. Clicking it automatically assigns your user as the technician and sets today's date as the assignment date — no need to manually select yourself from the dropdown and save.

In debug mode the button also displays the model name and record ID for easier troubleshooting.

**Runs on:** `https://*.odoo.com/*`
